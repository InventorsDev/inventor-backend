POST /admin/lead-candidates
{
  "email": "john@example.com",
  "sessionId": "...",
  "position": "BACKEND_LEAD"
}
1. Validate session
2. Validate position
3. Find user by normalized email
4. Check existing candidate
5. Check existing assignment
6. Create candidate
7. If user exists:
       associate user
       create in-app notification
   else:
       send invitation email
8. Record invitation event
----
existing user
admin_invites => Email exists => candidate.userId = existing userid => notify => user accepts

new user
admin_invites => email X=> candidate.userId = null => invitation token created=> email sent => user registers => registration consumes invitation token => candidate.userId = newUser.id => user accepts
